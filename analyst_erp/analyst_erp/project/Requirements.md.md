# System Requirements

## 1. Authentication

Sistem harus menyediakan:

- Login
- Register
- Logout
- Role-based access
- JWT authentication

## 2. User Roles

Sistem memiliki role:

- Admin
- Customer

## 3. Admin

Admin dapat:

- mengelola data
- melihat dashboard
- mengelola pengguna
- mengelola produk

## 4. Customer

Customer dapat:

- melihat produk
- melakukan pemesanan
- melihat status pesanan
- mengelola akun
